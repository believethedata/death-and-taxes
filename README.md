# death-and-taxes

This repo contains all the data and code used to produce the [Politics, religion, death and taxes](https://believethedata.org/) article.

The full workflow for the analysis behind the article is contained in the `analysis.ipynb` notebook.

The `wave31_subset_cols.parquet` data contained in this folder contains a subset of columns from the latest wave of the [British Election Survey](https://www.britishelectionstudy.com/data-object/wave-31-of-the-2014-2026-british-election-study-internet-panel/).

Plots in the article were created using [Datawrapper](https://www.datawrapper.de/) based on data output by the `analysis.ipynb` notebook to the `plot_data` folder.
